Для загрузки списка домов, устройств и сценариев используется защищённый обработчик API. Токен не публикуется в GitHub и не передаётся сервису подписи команд. Пока обработчик не развёрнут, тестовый пример доступен, но реальный дом загрузить нельзя.

1 Подключите свой Яндекс Умный дом

Не нужно искать ID устройств вручную. Авторизация происходит на стороне Яндекса; для чтения списка нужен одноразовый запрос через наш сервер.

Способ 1. Войти через Яндекс ID

Перейдите на официальный сайт Яндекса, разрешите доступ и вернитесь сюда. Токен будет автоматически перенесён в поле ниже только в этой вкладке. Когда серверный обработчик подключён, устройства загрузятся после вашего подтверждения.

🔐 Войти через Яндекс

Токен хранится только в памяти этой вкладки. В файл команды, в URL сайта и в GitHub он не попадает.
