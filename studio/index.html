Способ 1. Войти через Яндекс ID

Официальная кнопка Яндекс ID загружается при открытии конструктора и может показать текущий аккаунт Яндекса. Для её работы браузер обращается к Яндексу; в браузерах с ограничением сторонних cookie могут отображаться только обычные варианты входа.

Если кнопка не появляется, воспользуйтесь обычным входом или выбором другого аккаунта. Само посещение страницы не является согласием на управление умным домом.

Перейдите на официальный сайт Яндекса, разрешите доступ и вернитесь сюда. Токен будет автоматически перенесён в поле ниже только в этой вкладке. После вашего согласия проверим токен на реальном API и загрузим устройства именно выбранного аккаунта.

Яндекс может запомнить предыдущую учётную запись. Нажмите «Выбрать другой аккаунт», чтобы Яндекс снова показал выбор аккаунта и подтверждение доступа.
