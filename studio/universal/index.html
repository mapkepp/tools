Универсальная Apple Команда «Мой дом»

Здесь можно получить личный токен Яндекс Умного дома и подписать экспериментальную нативную Apple Команду v3. Главный сайт Mapkepp не изменяется.

1. Получить токен Яндекса

Нажмите кнопку — откроется официальный Яндекс ID. После разрешения доступа вы автоматически вернётесь сюда через проверенный OAuth callback.

Токен ещё не получен.

Важно: токен предоставляет доступ к устройствам. Он остаётся только в оперативной памяти этой вкладки, не попадает в ссылку, аналитику, GitHub или на сервер подписи. Скопированный токен сохранится в буфере обмена устройства, пока вы его не очистите.

2. Подписать Apple Команду v3

Выберите Mapkepp-My-Home-Native-v3-UNSIGNED.shortcut из ранее скачанного архива разработки. Допускается только контрольный файл v3 с демонстрационными устройствами. Токен внутрь файла не встроен — iPhone попросит его при импорте.

Файл не выбран.

Ожидает файл.

📥 Сохранить подписанную .shortcut

Это этап проверки подписи и импорта. В v3 — демонстрационные ID; до персонализации команда не сможет управлять вашими устройствами. Работу на Apple Watch ещё предстоит проверить.

3. Дальнейшая персонализация

Для реальных устройств используйте уже работающий конструктор Studio и сохраните локальный список устройств. Универсальная v3 пока не умеет создавать подписанный персонализированный файл непосредственно из этого каталога. Мы не будем выдавать демонстрационный файл за готовую команду реального дома.

Сервис подписи не меняет существующий обработчик основной Studio. Не загружайте файлы с токенами, паролями, cookies и личными данными.
