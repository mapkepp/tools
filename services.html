Используемые сервисы, лицензии и права

Mapkepp Tools — независимый бесплатный проект. Указанные ниже организации не являются нашими спонсорами и не обязаны поддерживать наши инструменты. Названия используются для объяснения совместимости и фактически применяемых сервисов.

Яндекс ID и Яндекс Умный дом

Официальная авторизация через Яндекс ID и API Яндекс Умного дома. Запрашиваются права для просмотра и управления устройствами. При наличии разрешений профиля отдельно отображаются имя и аватар. Пользователь сам выдаёт и может отозвать разрешение.

Документация Яндекс ID · Условия использования Яндекс ID API · Документация Умного дома

Не удаляем и не подменяем знаки и сообщения Яндекса в его интерфейсах. Проект не заявляет об официальном одобрении Яндексом.

Apple «Команды» (Shortcuts)

Создаём конфигурационные файлы для приложения Apple «Команды». Импорт и разрешения контролирует операционная система устройства. Apple не участвует в разработке Mapkepp Tools.

Shortcuty Signing API

Независимый внешний сервис подписывает создаваемые файлы .shortcut. Передача осуществляется только после согласия пользователя. При обычной подписи OAuth-токен исключён, но сервису доступны имя, ID выбранного устройства и действия команды. Специальный режим со встроенным токеном отдельно предупреждает, что токен будет передан Shortcuty и вписан в файл.

QRCode.js (davidshimjs)

Локальное создание QR-кодов на устройстве пользователя, без передачи ссылки стороннему QR-провайдеру. QRCode.js — программная библиотека под MIT License.

GitHub Pages и Supabase

GitHub Pages размещает исходный код и статическую страницу. Supabase Edge Functions обеспечивает ограниченный HTTPS-запрос к API Яндекса, потому что браузер не может напрямую прочитать ответ из-за политики CORS. Сервер обрабатывает токен только на время запроса и не записывает его в базу данных. Параллельные обращения разных пользователей обрабатываются независимо, но возможны ограничения Яндекса и тарифов инфраструктуры. Для подписи команд без встроенного токена отдельная функция Supabase shortcut-sign пересылает исключительно XML-шаблон внешнему сервису Shortcuty и возвращает подписанный файл AEA1. Шаблоны и подписанные файлы не сохраняются нашим обработчиком; Shortcuty обрабатывает их согласно своим условиям. В Safari доступно сохранение файла и, если поддерживается, системное меню «Поделиться». При этом инфраструктурные технические журналы провайдера регулируются его условиями.

Локальная история и техническая диагностика

Настройки команд сохраняются в этом браузере только по кнопке «Сохранить текущую команду», без OAuth-токена. В них могут быть названия и ID устройств. Пользователь может полностью удалить историю или экспортировать её; автоматической облачной синхронизации нет.

При согласии на загрузку устройств приложение также передаёт в закрытые журналы Supabase обезличенные этапы загрузки: коды событий, HTTP-статусы, номера частей, длительность и объём передачи. Приложение не включает в эти события токены, IP-адреса, логины, идентификаторы, названия устройств либо содержимое запросов и ответов. Отдельная таблица кодов ошибок очищается по расписанию в пределах 14 дней; инфраструктурные логи Supabase, GitHub и Яндекса имеют собственные сроки хранения и политику провайдера. Умный дом запрашивается частями; запросов к API может быть несколько десятков в зависимости от размера списка. Между HTTP-запросами приложение не сохраняет токен на сервере.

Добровольная поддержка автора

Независимые сервисы ЮMoney и Т-Банк обслуживают добровольные переводы. Все функции проекта доступны бесплатно, без привилегий за перевод. Оплату, обработку платёжных данных и свои правила устанавливают соответствующие организации.

Приватность ссылок: ссылки и QR-коды на готовые конфигурации содержат параметры устройства и действия, но не ваш токен. Если вы сознательно создаёте файл со встроенным токеном, он даёт получателю доступ к вашему умному дому. Не публикуйте такой файл и при компрометации отзовите доступ в Яндекс ID.
