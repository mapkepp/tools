Что получится

Предпросмотр HTTP-запроса. OAuth-токен вводится непосредственно на iPhone при добавлении команды.

В этом ручном генераторе OAuth-токен вводится уже на iPhone.
Расширенный конструктор по домам и комнатам работает иначе: после вашего согласия токен на время запроса передаётся защищённому серверу Mapkepp Tools для получения списка устройств из Яндекса. Он не сохраняется в базе. Сервисы и приватность.


Установка на iPhone
  1. Создайте команду и скачайте подписанный файл.
  2. Откройте файл в приложении «Команды».
  3. Введите собственный OAuth-токен с доступом iot:control без Bearer.
  4. Если включили авто-VPN — выберите свой VPN-профиль для отключения и повторного подключения.
  5. Проверьте действие на реальном устройстве.


Что, если подпись не скачалась?
Сервис Shortcuty является независимым сторонним провайдером и может быть недоступен. Скачайте неподписанный файл, затем подпишите его через страницу Shortcuty вручную. Неподписанный файл iOS обычно не импортирует.


Почему VPN не обходится напрямую?
Apple «Команды» не умеют выбирать сетевой маршрут для конкретного запроса. Экспериментальная опция временно отключает VPN, что уменьшает защищённость соединения. Надёжный вариант без разрыва — раздельная маршрутизация в VPN-клиенте.
