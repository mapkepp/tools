# Передача Apple Команд, QR-коды, Яндекс ID и OAuth-токены

Дата реализации: 22 октября 2026. Главная страница: https://mapkepp.github.io/tools/studio/

## Обычная отправка другому устройству — безопасный режим по умолчанию

1. На Windows, Android, iPad или компьютере откройте [конструктор](https://mapkepp.github.io/tools/studio/), войдите через Яндекс, выберите дом, комнату и устройство или сценарий, укажите действие.
2. Нажмите **«Создать ссылку»**. Получите самодостаточную ссылку вида `https://mapkepp.github.io/tools/studio/#config=...`. В ней сохранены имя, ID устройства, тип действия, его значение и название команды, но **нет OAuth-токена**. Ссылка не требует нашей базы данных или аккаунта Mapkepp.
3. Используйте **«Скопировать ссылку»** для мессенджера или **«Показать QR-код»** для считывания камерой iPhone. QR создаётся **локально** с помощью QRCode.js MIT, без передачи настроек сторонним QR-сервисам.
4. Получатель открывает ссылку, видит уже настроенную команду, подтверждает передачу **шаблона без токена** на независимый подписывающий сервис Shortcuty и скачивает подписанный файл `.shortcut`.
5. При установке Apple «Команды» просят **собственный** OAuth-токен. Подсказка в установке указывает адрес Mapkepp Tools и путь: войти через Яндекс → скопировать токен → вставить его при импорте.
6. Пользователь вводит токен аккаунта, которому Яндекс разрешает управление именно этим устройством. Если получатель **не имеет доступа** к чужому умному дому, команда не будет работать — только получение вашей ссылки не выдаёт доступ к вашему Яндексу.
7. Если пользователь открыл ссылку и вошёл через Яндекс, настройки временно сохраняются через `sessionStorage` при OAuth-переходе и восстанавливаются на странице без помещения токена в публичный URL.

**Приватность:** ссылка содержит ID устройства и названия — это непубличная информация о вашей конфигурации, но сама по себе **не является ключом управления**. Делитесь ею осознанно. Публичный GitHub не хранит такие ссылки или токены.

## Копирование личного токена

После входа в Яндекс токен доступен в скрытом поле конструктора. Кнопка **«📋 Скопировать мой токен»** переносит его в буфер устройства. Не публикуйте его. После установки лучше очистить буфер обмена и нажать **«Очистить токен»** в браузере.

## Отображение аккаунта Яндекса

После успешной загрузки данных дома конструктор пытается показать логин через официальный `GET https://login.yandex.ru/info` с `Authorization: OAuth` через отдельную Supabase Edge Function `yandex-profile`. Возвращаются только отображаемое имя, логин и идентификатор аватара. Токен и профиль не сохраняются на сервере и в GitHub. Фото загружается по официальному адресу `avatars.yandex.net`.

Какие поля доступны, зависит от разрешений приложения. Для полного имени и портрета в настройках OAuth-приложения могут потребоваться `login:info` и `login:avatar`; без них конструктор корректно показывает заглушку. **Не включайте дополнительные разрешения, пока пользователь не дал согласия и настройки приложения не обновлены.**

## Специальный опасный режим: передать команду со встроенным токеном

Он находится в сворачиваемом блоке после настройки команды. Пользователь должен:
- отметить **два отдельных предупреждения** о доступе получателя к его умному дому и передаче токена внешнему подписывающему сервису;
- ввести вручную фразу **«ПЕРЕДАТЬ ДОСТУП»**;
- подтвердить подпись и принять последнее системное предупреждение.

В результате формируется файл с **OAuth-токеном открытым текстом**, отправляемый непосредственно в **Shortcuty** для подписи, а затем скачиваемый на устройство пользователя. **Этот вариант небезопасен**, так как токен узнаёт внешний подписывающий сервис, а получатель файла может управлять вашими устройствами с разрешениями токена. Он **не размещается** в GitHub, обычной ссылке и QR-коде. Не используйте его для открытой публикации или незнакомых людей.

При подозрении на компрометацию отзовите доступ приложения в настройках Яндекс ID и выпустите новый токен. Учитывайте правила Яндекса и договорённости об использовании учётной записи.

**Рекомендация:** по умолчанию делиться только конфигурацией без токена, а управлять устройствами с личного аккаунта получателя или официально предоставленным доступом.

## Используемые сервисы

Подробно: [страница сервисов и лицензий](https://mapkepp.github.io/tools/services.html), включая требования по копирайту и MIT-уведомление QRCode.js. В работе используются Yandex ID, Yandex Smart Home API, Apple Shortcuts, GitHub Pages, Supabase, Shortcuty, QRCode.js, ЮMoney и Т-Банк. Проект не является официальным сервисом Яндекса и Apple.
