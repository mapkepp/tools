## Границы реализованного

1. **Реальный пользовательский дом.** В логах Supabase был как минимум один `POST 200` от `yandex-home` вечером 22.10.2026, однако без персональных данных невозможно связать его с конкретным посетителем. После актуальных исправлений нет подтверждённого E2E-прогона на реальном домашнем аккаунте. Для него пользователь входит через Яндекс в своей вкладке и нажимает «Загрузить мои устройства». Токен в чате не нужен.
2. **Синхронизация истории между устройствами:** ещё не реализована. Сейчас предлагаются ссылка, QR и JSON-экспорт. Публиковать историю на сервере без явного разрешения пользователя нельзя.
3. **Комментарии/отзывы авторизованных пользователей:** обсуждались как возможное развитие, но не включены в релиз. Требуются правила модерации, хранения и безопасная привязка к личности; без этого нельзя выдавать сервис публичных комментариев за готовый.
4. **Старый iPhone discovery helper** удалён из основного сценария, но файл сохранён как legacy/совместимость, потому что отсутствие внешних потребителей не доказано. Это соответствует новому канону о рудиментах.
5. **Новый протокол канона** закоммичен и machine manifest связан с Git blob SHA. GitHub Actions Canon Evals и Obsidian Sync в частном репозитории завершились до запуска своих шагов (failure/no runner steps): автоматическая синхронизация Obsidian и runtime Hermes не подтверждена.
6. **Персональные данные и законность:** приложение не помещает OAuth-токены или данные дома в технический журнал и не публикует их на GitHub. Инфраструктурное логирование облачных провайдеров регулируется их правилами; этот репозиторий не является юридическим заключением.
