# Добровольная поддержка Mapkepp Tools

Донаты — это добровольные пожертвования. Они не открывают никакого дополнительного функционала и не дают преимуществ. Весь функционал доступен сразу всем полностью бесплатно, независимо от пожертвований.

Поддержать проект можно через [Т-Банк](https://t.tb.ru/pm_short/7Ixu10XDRWa) или [ЮMoney](https://yoomoney.ru/fundraise/1L2T11QBAHF.261022).

## Безопасность

- Номер основного сбора: `1L2T11QBAHF.261022`.
- Прямая ссылка и виджет на странице ведут к **одному и тому же сбору**.
- Другой номер из исходного HTML (`1L2T0DHO0U5.261022`) намеренно не используется, чтобы не смешивать два сбора.
- Виджет ЮMoney загружается только после отдельного нажатия посетителя. Сайт не принимает данные карт и не хранит платёжные сведения.
- `.github/FUNDING.yml` содержит только ссылку, которую пользователь предоставил; обработка платежей на стороне ЮMoney.

- Налоговая квалификация поступлений определяется по фактическим обстоятельствам и условиям платёжного провайдера; текст на сайте сам по себе не делает перевод освобождённым от налогообложения.
