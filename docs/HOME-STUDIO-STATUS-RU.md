## Что можно попробовать уже сейчас

**Сайт:** https://mapkepp.github.io/tools/studio/

1. Откройте конструктор в Safari на iPhone.
2. При необходимости воспользуйтесь кнопкой «Получить разрешение у Яндекса» (официальная страница Яндекса). В её адресе указан ранее предоставленный владельцем Client ID `a0f04364eb374e6a9297ca708c959218`; **подтверждение настройки приложения, его OAuth-политик и конечных прав — NOT_TESTED**. Redirect URI должен быть зарегистрирован как `https://mapkepp.github.io/tools/oauth/callback.html`, иначе Яндекс может направить на другую страницу или выдать ошибку.
3. Скачайте и установите [подписанного помощника](https://mapkepp.github.io/tools/ios/Yandex_Home_Discovery.shortcut). При установке введите личный токен Яндекса с `iot:view` прямо на iPhone; токен не публикуется и не пересылается в сервис подписи. Запустите команду, чтобы получить список.
4. Вставьте JSON со списком домов/комнат/устройств/групп/сценариев из буфера или импортируйте JSON-файл. При проблемах с форматированием ответа на реальном iOS требуется доработать экспорт помощника.
5. Найдите нужный объект по названию, названию комнаты или дома. Выберите действие, которое поддерживается устройством, затем нажмите «Подписать и скачать».
6. На iPhone импортируйте подписанную команду, введите токен при установке. Это **не** одноразовое общее хранилище токенов; для повторного использования потребуется отдельная архитектура iOS.

## Обязательные ограничения

- **Единая кнопка «Войти в Яндекс → загрузить все устройства» не готова.** GitHub Pages — статический хостинг; CORS preflight для `https://api.iot.yandex.net/v1.0/user/info` не предоставил `Access-Control-Allow-Origin`. Яндекс OAuth токен можно получить на устройстве, но прямой браузерный запрос к списку блокируется. Для однокнопочного веб-режима нужен доверенный серверный компонент, например serverless endpoint в управляемом владельцем Vercel, с явным информированием пользователя о передаче токена (хотя бы в памяти запроса), строгой политикой CORS, отсутствием журналирования содержимого и ограничением частоты. Прежде чем внедрять, проверить правила Яндекса и обработку персональных данных.
- Текущий экспорт через Apple «Команды» — **NOT_TESTED** на реальном iPhone: файл подписан, но доступность действий и формирование строгого JSON из ответа словаря Яндекса нуждаются в практической проверке.
- Импорт JSON и дерево по массивам официального API: **PASS** на моделируемой структуре; реальный экспорт пользователя **NOT_TESTED**.
- Отдельный список сценариев предусмотрен специально: официальный API не возвращает их привязку к комнатам.
- Для неподдерживаемых умений кнопка создания отключается. Доступны on/off, числовые range, поддерживаемые color temperature, mode и запуск активных сценариев.
- Команды пока имеют один выбранный эффект на объект; цепочки из нескольких действий — будущая функциональность.
- Подпись `.shortcut` требует внешнего сервиса; в отправляемом файле **нет OAuth-токена**. Выбор устройства и его ID сторонний подписывающий сервис видеть может. Требуется явное согласие.
